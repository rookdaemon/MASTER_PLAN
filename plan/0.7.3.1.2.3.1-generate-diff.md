# 0.7.3.1.2.3.1 Generate Diff [PLAN]

## Description
Create a textual diff that captures the change to the `src/plan-guardian/` line inside `docs/codebase-map.md`, showing the exact line removed and the line added, with line numbers and a few lines of surrounding context.

## Acceptance Criteria
1. The diff is produced using a standard diff format (unified diff) with `@@` hunk headers.  
2. It clearly marks the removed line (`-`) and the added line (`+`).  
3. At least three lines of context before and after the changed line are included.  
4. No other unrelated file sections are included in the diff.  
5. The diff output is stored in a variable or temporary file for the next step.
