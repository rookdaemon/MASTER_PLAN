# 0.1.2.2.2 Biological Predictions Verified [PLAN]
## Description

Preregister, conduct, and analyze the biological experiments needed to test IRSM predictions across anesthesia, split-brain or equivalent dissociation, neural perturbation, and altered-consciousness paradigms.

## File Manifest
- docs/consciousness-science/predictive-consciousness-models.md

## Acceptance Criteria
- Each experiment identifies its ethics approval, preregistration, responsible group, dated dataset, and reproducible analysis
- Results report effect sizes, confidence intervals, hypothesis-test outcomes, exclusions, and deviations from protocol
- At least one biological prediction discriminates IRSM from its stated null and matches the preregistered IRSM prediction
- Null, partial, and mismatching results are retained and discussed without relabeling targets as observations
