# 0.2.2.1.2.1.3 Preservation Validation [PLAN]

## Description

Measure preservation error across the declared whole-brain specimen and determine whether the protocol satisfies every L2+ preservation threshold.

## Acceptance Criteria

- Preregistered before/after or matched-control assays independently measure morphology, receptor distributions, neurotransmitter baselines, glial topology, and ion-channel-state proxies.
- Sampling covers anatomically distributed regions, including expected worst-case stabilization locations, with justified statistical power.
- Results report bias, variance, spatial nonuniformity, missing data, and uncertainty against each registered threshold.
- Raw observations, provenance, analysis parameters, and pass/fail results are traceable and reproducible.
