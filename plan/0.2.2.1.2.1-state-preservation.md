# 0.2.2.1.2.1 State Preservation [PLAN]

## Description

Develop and validate the fixation or vitrification protocol that freezes an intact brain's L2+ structural and dynamic state before acquisition.

## Acceptance Criteria

- A specimen scale and maximum fixation time are stated with a justified brain-state drift tolerance.
- The protocol preserves morphology, neurotransmitter baselines, receptor distributions, and ion-channel-state proxies required by L2+.
- Independent before/after measurements quantify preservation error against registered thresholds.
- Destructive preparation is justified against evaluated non-destructive alternatives.
