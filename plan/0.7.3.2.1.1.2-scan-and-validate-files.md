# 0.7.3.2.1.1.2 Scan and Validate Files [PLAN]

Automate a directory walk of the traceability package, checking that each required artifact exists and that its filename conforms to the pattern defined in the inventory.

**Acceptance Criteria**
1. A script (e.g., Python or Bash) is written and stored at `tools/validate_artifacts.py`.
2. The script reads `artifact-inventory.md` and outputs a JSON report of found/missing/incorrect‑name files.
3. All required artifacts are reported as “found” with correct naming.
4. Any file that does not match the naming convention is flagged as “incorrect name”.
5. The script runs without errors on the reference package directory and produces the report file `validation-report.json`.
