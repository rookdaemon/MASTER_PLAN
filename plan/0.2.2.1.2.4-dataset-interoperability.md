# 0.2.2.1.2.4 Dataset Interoperability [PLAN]

## Description

Specify, implement, and validate the versioned scan dataset exchanged with the neural-simulation pipeline.

## Acceptance Criteria

- The schema represents every required L2+ structural and dynamic-state field, provenance, units, uncertainty, and per-region integrity data.
- Serialization round-trips representative full-shape records without semantic loss and rejects invalid or incomplete records.
- Storage layout supports chunked and parallel access at the declared whole-brain scale.
- A contract test proves that 0.2.2.1.3 can consume the versioned dataset without an undocumented transformation.
